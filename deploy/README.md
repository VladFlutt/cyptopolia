# Развёртывание Криптополии

Вся игра работает на одном сервере: игровая сеть, бэкенд и HTTPS. Ниже два варианта хостинга. Команды на сервере в обоих случаях одинаковые, отличается только то, где взять сервер.

## Какой сервер нужен

| Нагрузка | Сервер | Hetzner (примерно) | Россия (примерно) |
| --- | --- | --- | --- |
| Пилот, до ~200 партий одновременно | 2 vCPU, 4 ГБ, 40 ГБ NVMe | CX22, ~4–5 € в месяц | Timeweb Cloud / Selectel, ~500–900 ₽ в месяц |
| До 1000 партий одновременно | 4 vCPU, 8 ГБ, 80–160 ГБ NVMe | CPX31, ~13–15 € в месяц | Timeweb Cloud / Selectel, ~1 500–2 500 ₽ в месяц |

Цены приблизительные, их нужно проверить у провайдера перед заказом. Система: Ubuntu 24.04.

## Вариант 1. Hetzner Cloud

1. Создайте проект в Hetzner Cloud Console и сервер CX22 (для пилота) в локации Helsinki или Falkenstein. Образ Ubuntu 24.04, добавьте свой SSH-ключ.
2. В разделе Firewalls разрешите входящие порты 22, 80 и 443.
3. Дальше выполните «Общие шаги» ниже.

Учтите: Hetzner может не принять оплату или аккаунт от резидентов РФ. В этом случае используйте вариант 2.

## Вариант 2. Российский хостинг (Timeweb Cloud, Selectel)

1. Создайте облачный сервер с Ubuntu 24.04 и нужной конфигурацией (таблица выше), добавьте SSH-ключ.
2. В настройках сетевого экрана откройте порты 22, 80 и 443.
3. Docker Hub и ghcr.io из России иногда работают медленно или с ошибками. Если `docker compose pull` падает, подключите зеркало реестра, например `https://mirror.gcr.io` или зеркало вашего провайдера:
   ```bash
   echo '{ "registry-mirrors": ["https://mirror.gcr.io"] }' | sudo tee /etc/docker/daemon.json
   sudo systemctl restart docker
   ```
4. Дальше выполните «Общие шаги» ниже.

Персональные данные: бэкенд хранит адреса кошельков и имена, которые игроки вводят сами. Попросите игроков использовать никнеймы вместо настоящих имён, тогда вопросов по 152-ФЗ не возникает.

## Общие шаги

### 1. Адрес сайта без своего домена

Домена пока нет, поэтому используем бесплатный сервис [sslip.io](https://sslip.io): имя `203-0-113-7.sslip.io` само указывает на IP `203.0.113.7`. Caddy получит для него настоящий сертификат Let's Encrypt, и кошельки примут HTTPS-адрес сети. Подставьте IP своего сервера через дефисы.

Когда появится свой домен (например, `.ru` стоит ~200 ₽ в год), направьте A-запись на сервер и поменяйте `PUBLIC_URL` и `SITE_HOST` в `deploy/.env`. Игрокам придётся заново добавить сеть в кошелёк, потому что поменяется адрес RPC.

### 2. Установка

```bash
# Docker
curl -fsSL https://get.docker.com | sudo sh

# Код
sudo git clone https://github.com/VladFlutt/cyptopolia /opt/cryptopolia
cd /opt/cryptopolia

# Секреты: ключ оператора, фраза для кошельков банков, параметры сети.
# Вместо 0xВашКошелёк укажите адрес своего кошелька: он станет суперадмином.
sudo apt-get install -y nodejs npm
cd backend && npm ci && npx tsx scripts/init-env.ts https://203-0-113-7.sslip.io 0xВашКошелёк && cd ..

# Запуск
cd deploy && sudo docker compose up -d --build
```

При первом старте бэкенд сам развернёт контракт SessionManager и запомнит его адрес в базе.

### 3. Проверка

```bash
curl https://203-0-113-7.sslip.io/api/health     # {"ok":true,"block":...}
curl https://203-0-113-7.sslip.io/api/config     # параметры сети для кошелька
```

### 4. Резервные копии

```bash
sudo crontab -e
# добавить строку:
0 4 * * * /opt/cryptopolia/deploy/backup.sh
```

Скрипт каждую ночь сохраняет состояние сети и базу в `/var/backups/cryptopolia` и хранит копии 14 дней.

### 5. Сброс сети (раз в квартал или при нехватке диска)

Сеть и база сбрасываются только вместе, иначе бэкенд откажется стартовать:

```bash
cd /opt/cryptopolia/deploy
sudo docker compose down
sudo docker volume rm deploy_chain-data deploy_backend-data
sudo docker compose up -d
```

Игрокам ничего делать не нужно: chainId и адрес RPC остаются прежними.

## Что хранить в секрете

Файл `deploy/.env` содержит ключ оператора и фразу, из которой выводятся кошельки банков всех партий. Утечка не грозит реальными деньгами (всё игровое), но позволит вмешаться в партии. Не коммитьте этот файл, он уже в `.gitignore`.
